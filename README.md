# ratneshjais.github.io

Source for my profile site: [ratneshjais.github.io](https://ratneshjais.github.io).

Next.js (App Router) and Tailwind CSS v4, exported as static HTML and deployed to GitHub Pages by
`.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

All copy lives in `src/content/profile.ts`. The resume download is `public/Ratnesh_Jaiswal_Resume.pdf`.
